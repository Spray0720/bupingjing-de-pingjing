## 设计思路

两个游戏共用同一套结构：

| 元素 | 作用 |
| --- | --- |
| 分页故事 | 每页一个场景，左图右文 |
| 阅读指引 | 折叠面板，说明本关在练什么思维技能 |
| 插图 | 每页一张，标注地点、人物、关键观察点 |
| 推理题 | 读完即答，答对/答错都有解释 |
| 线索本 | 把关键证据收进口袋，跨页累积 |
| 结局判定 | 线索不够就结不了案 |

核心想法：**把科学史上的真实推理过程，还原成读者自己能走一遍的路径。**
